# Notices

This directory serves an in-browser speech-to-text model. It includes or loads the following third-party work.

- Whistle model by Cactus Compute, Apache-2.0. https://huggingface.co/Cactus-Compute/whistle
- Browser port (ONNX graphs, weight pack, worker and JavaScript pipeline) from mrfakename/whistle-webgpu, Apache-2.0. https://huggingface.co/spaces/mrfakename/whistle-webgpu
- onnxruntime-web, MIT, loaded at runtime from jsDelivr. https://www.npmjs.com/package/onnxruntime-web
